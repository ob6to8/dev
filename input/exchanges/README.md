#human-authored

Exchanges represent atomic single turn operator-agent prompt-response interacitions.
./Exchanges is a dated titled immutable series of files persisting each exchange in sequential order of creation.
When exchanges reference other exchanges, or multiple exchanges, this is represented in the metadata as links to exchange files themselves.
In this way, "threads" become linked lists.
Threads are documents recording series of connections between exchanges. This externalizes the connections between exchanges.
