Pull requests are auditing at the wrong stage of the process. Pull requests of agent code are currently discovery - "what did the agent do, and do I see any issues jump out at me" inviting cursory examination and rubber stamping. Instead, all of the work should occur iteratively, and commit atomic enough, to where the PR review should only be a double check that everything agreed on appears in line with the intermediate abstract spec layer (or something)
