#human-authored

I am considering 4 possible agent types for dev:

1. Ideation: Questions and discussion (output is an exchange, but an exchange of type: plan. Side effects are web search and grep.)
2. Review: Automated adversarial review of an exchange (output is an exchange, of type: review. Side effects are web search and grep.) 
3. Implementation: Committed code or prose (Output is an exchange with notes on the build, side effects are document writes.)

The review agent would be callable after both ideation and Implementation. It may be worth considering Review and Audit agents to be separate.
